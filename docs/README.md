## Contributing to Documentation

We follow professional documentation standards:

- **Naming**: All files use `kebab-case.md` format
- **Structure**: Maximum 3-click depth to any information
- **Templates**: Use provided templates for consistency
- **Cross-references**: Keep internal links updated
- **Reviews**: All documentation changes should be reviewed

See our [Documentation Templates](templates/) for standardized formats.
